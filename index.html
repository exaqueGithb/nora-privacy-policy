NORA

개인정보처리방침

시행일: 2026년 8월 19일 · 적용 대상: NORA Android 앱 (패키지 ID: com.jiwxn3.karaoke)

요약: NORA는 보컬 연습을 돕는 앱입니다. 마이크 신호는 기기 안에서 피치·리듬 분석에 사용되며, 원본 음성을 저장하거나 서버로 전송하지 않습니다. 점수·즐겨찾기·설정은 기본적으로 사용자의 기기에만 저장됩니다.

1. 적용 범위

이 개인정보처리방침은 NORA Android 앱의 정보 처리 방식에 적용됩니다. NORA는 계정 생성이나 자체 클라우드 동기화를 요구하지 않으며, 광고를 제공하지 않습니다.

2. 처리하는 정보와 목적

정보 또는 권한처리 목적과 방식
마이크 신호사용자가 Luna VoiceAssist의 발성 분석을 시작한 경우에만 현재 음정, 안정도, 리듬 규칙성을 기기 내에서 분석합니다. 원본 음성 녹음 파일을 저장하거나 NORA 서버로 전송하지 않습니다.
연습 기록·점수곡 제목, 점수, 피치·타이밍·안정도 요약, 세션 모드와 집중 시간을 사용자의 기기 데이터베이스에 저장합니다. 사용자는 앱 설정에서 기록을 JSON으로 내보내거나 삭제할 수 있습니다.
즐겨찾기·설정즐겨찾는 곡, 메트로놈·인이어 관련 설정, 앱 사용 흐름을 위해 기기에 저장합니다.
검색어·네트워크 요청사용자가 NORA 노래방 검색을 실행할 때 입력한 검색어, 검색 소스 및 요청 IP 주소를 NORA 검색 서비스가 공개 YouTube 결과 제공과 요청 한도 관리에 사용합니다. IP 기반 요청 횟수는 서버 메모리에서 최대 1분 동안, 검색 결과와 검색어 조합은 서버 메모리에서 최대 5분 동안 유지될 수 있으며, 계정과 연결하거나 별도 사용자 데이터베이스에 저장하지 않습니다.
인터넷 연결사용자가 요청한 경우 공개 YouTube 검색 결과를 앱 안의 공식 임베디드 플레이어에서 재생하거나, 공식 YouTube Android 앱을 NORA와 나란히 열도록 요청하거나, 같은 Wi‑Fi의 사용자가 선택한 Windows 미러링 수신기와 연결하는 데 사용합니다.
Bluetooth·오디오 장치 정보사용자가 인이어 모드를 사용할 때 연결된 Bluetooth 또는 유선 오디오 장치를 식별하고, 메트로놈 출력과 입력 장치 선택을 돕기 위해 기기 안에서 사용합니다.

3. 제3자 서비스

NORA는 사용자가 누른 경우에만 공개 YouTube 검색 결과를 표시하고, 공개 YouTube 링크를 YouTube의 공식 임베디드 플레이어로 표시하거나 공식 YouTube Android 앱을 NORA와 나란히 열도록 요청할 수 있습니다. 이 기능을 사용하면 YouTube 및 Google이 해당 서비스의 정책에 따라 정보를 처리할 수 있습니다. NORA는 YouTube 영상·오디오·썸네일 파일을 다운로드, 추출 또는 자체 저장하지 않으며 YouTube 광고·실제 재생 시간·영상 상태를 읽거나 제어하지 않습니다. YouTube 사용에는 YouTube 서비스 약관 및 Google 개인정보처리방침이 적용됩니다.

선택적 Windows 미러링 기능은 사용자가 같은 Wi‑Fi에서 지정한 로컬 수신기와만 통신하도록 설계되어 있습니다. NORA는 이 연결을 위한 자체 원격 서버를 운영하지 않습니다.

4. 정보 보관·내보내기·삭제

로컬 연습 기록과 즐겨찾기는 사용자가 삭제할 때까지 기기에 보관됩니다. 사용자는 앱의 설정에서 데이터를 JSON 파일로 내보내거나, 모든 로컬 기록과 즐겨찾기를 삭제할 수 있습니다. 앱을 삭제하면 일반적으로 앱의 로컬 데이터도 운영체제 정책에 따라 삭제됩니다.

5. 데이터 삭제 요청

NORA는 계정이나 NORA 운영 서버의 사용자 데이터베이스를 운영하지 않습니다. 따라서 연습 기록, 점수, 즐겨찾기 및 설정은 사용자의 기기에만 존재합니다. 사용자는 앱의 설정에서 로컬 기록과 즐겨찾기를 즉시 삭제할 수 있으며, 앱을 삭제하면 일반적으로 해당 앱의 로컬 데이터도 운영체제 정책에 따라 삭제됩니다.

앱에 접근할 수 없거나 삭제 과정에 도움이 필요한 경우, 제목에 “NORA 데이터 삭제 요청”을 적어 WeirdPaper@yahoo.com으로 연락할 수 있습니다. NORA는 원격에 보관하는 연습 기록·음성 녹음·계정 데이터가 없으므로, 지원은 기기 내 삭제 방법 안내를 제공하는 방식으로 이루어집니다. 사용자가 직접 내보낸 JSON 파일은 사용자가 저장한 위치에서 별도로 삭제해야 합니다.

YouTube 또는 Google이 독립적으로 처리하는 데이터의 삭제·보관 요청은 해당 서비스의 정책과 도구를 따라야 합니다. NORA는 YouTube에 저장된 데이터에 접근하거나 이를 대신 삭제할 수 없습니다.

6. 아동 및 연령

NORA는 13세 이상 사용자를 대상으로 합니다. NORA는 13세 미만 아동을 대상으로 설계되지 않았으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

7. 보안

NORA는 원본 음성의 서버 전송을 하지 않고, 연습 기록을 기본적으로 로컬에 저장하여 데이터 노출을 줄이도록 설계되었습니다. 다만 사용자가 데이터를 내보내거나 외부 YouTube·Windows 기능을 사용하면 해당 파일·서비스·네트워크의 보안은 사용자의 환경과 해당 서비스 정책의 영향을 받을 수 있습니다.
